AgilePoint NX10 - OpenAI 整合操作教學

01 Global Access Token 01
進入 AgilePoint NX 管理介面，點選Add Token新增設定。123
01 Global Access Token 02
點擊新增 OpenAI。
01 Global Access Token 03
輸入自定義名稱並填入從 OpenAI 官網取得的 API 金鑰(須付費)，完成全域存取設定。
02 eForm 01
在 eForm 表單設計器中，進行配置(如圖:AutoLoopUp*1、Text Area*2、Button*1)。
02 eForm 02
編輯AutoLoopUp，選擇/新增 LoopUp，並且設定Access Token(Open AI)。
02 eForm 03
配置 OpenAI 活動的輸入參數與模型屬性。

Model Properties 頁籤：調整 AI 的「性格與精準度」
模型參數 (Parameter) 建議設定值 說明 (Description)
Model gpt-4o / gpt-3.5-turbo 選擇欲呼叫的 OpenAI 模型版本。
Temperature 0.7 控制回應的隨機性。數值愈低愈嚴謹，愈高愈具創意。
Max Tokens 1000 單次模型生成回應的最大 Token 數量限制。
02 eForm 04
設定輸出對應，將 AI 產生的回應寫回至表單的指定欄位中。下圖表示紅色的一定要設定。
Prompt 核心要素 配置說明
System Prompt 定義 AI 的角色背景與行為準則（例：你是一位專業的法務助理）。
User Prompt 動態綁定表單輸入欄位，傳遞使用者實際要提問的內容。

02 eForm 06
請選擇Map OpenAI Response To App Schema，並點右側的放大鏡。
02 eForm 07
設定content至你的輸出欄位。
